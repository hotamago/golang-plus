# GoPlus Language Support

First-party VSCode extension for **GoPlus** (`.gp`) — a productivity layer on top of Go with cleaner error handling, tagged enums, pattern matching, and compile-time decorators.

## Features

### 🎨 Syntax Highlighting

Full TextMate grammar for `.gp` files with highlighting for:

- **Keywords**: `fn`, `struct`, `enum`, `impl`, `match`, `return`, `if`, `for`, `defer`, `go`
- **Types**: Built-in types (`string`, `int`, `bool`, `error`) and PascalCase type references
- **Decorators**: `@log`, `@retry(3, 100)`, `@memoize`, `@derive(String, Debug)`
- **Enum variants**: `Status::Running`, `Result<T>::Ok(value)`
- **Operators**: `->` (return), `=>` (match arm), `::` (variant), `?` (try), `!` (error return)
- **Strings, comments, numbers**: Full support including escape sequences and block comments

### 🔍 Inline Diagnostics

Errors and warnings from `goplus check` and `goplus lint` appear as squiggly underlines directly in the editor, with:

- Severity level (error, warning, info, hint)
- Diagnostic code (e.g., `E0001`, `L0001`)
- Hints shown as related information

### 📋 Lint on Save

When you save a `.gp` file, `goplus lint` runs automatically and populates the **Problems** panel with style warnings and suspicious code diagnostics.

### 🧭 Bidirectional Source Navigation

- **`.gp` → `.go`**: Ctrl+Click (or F12) in a `.gp` file to jump to the corresponding location in the generated Go code
- **`.go` → `.gp`**: Ctrl+Click in a `zz_goplus_gen.go` file to jump back to the original GoPlus source

Uses source maps generated by `goplus transpile --emit-source-map`.

### ✨ Format on Save

`goplus fmt` integrates as a VSCode formatting provider. Enable `editor.formatOnSave` and your `.gp` files are automatically formatted on save with full undo/redo support.

### 📝 Snippets

Built-in snippets for rapid GoPlus development:

| Prefix | Description |
|--------|-------------|
| `fn` | Function declaration |
| `fne` | Function with error return (`T!`) |
| `main` | Main function with error return |
| `struct` | Struct declaration |
| `enum` | Simple enum |
| `enump` | Tagged enum with payload |
| `enumg` | Generic tagged enum |
| `match` | Match expression |
| `impl` | Impl block with method |
| `derive` | `@derive(...)` with kind picker |
| `@log` | Log decorator |
| `@retry` | Retry decorator |
| `@memoize` | Memoize decorator |
| `iferr` | Error propagation with `?` |
| `import` | Single import |
| `importg` | Grouped import |
| `decfn` | Custom decorator function template |

### 💡 Hover Information

Hover on GoPlus-specific syntax for contextual documentation:

- **Decorators** (`@log`, `@retry`, `@memoize`, `@derive`): Signatures, descriptions, and examples
- **Derive kinds** (`String`, `Debug`, `Equal`, etc.): Generated method signatures
- **`?` operator**: Try operator explanation with Go equivalent
- **`!` return type**: Error return type with mapping table
- **`::` operator**: Enum variant access
- **Keywords**: `match`, `fn`, `enum`, `struct`, `impl`, `self`

## Requirements

- [GoPlus compiler](https://github.com/hotamago/golang-plus) installed and available on PATH (or configure `goplus.binaryPath`)
- Go toolchain (for building generated code)

### Installing GoPlus

```bash
# Build from source
git clone https://github.com/hotamago/golang-plus.git
cd golang-plus
cargo install --path .
```

## Configuration

| Setting | Default | Description |
|---------|---------|-------------|
| `goplus.binaryPath` | `"goplus"` | Path to the `goplus` binary |
| `goplus.outDir` | `".goplusgen"` | Output directory for generated Go files and source maps |
| `goplus.checkOnSave` | `true` | Run `goplus check` on save |
| `goplus.lintOnSave` | `true` | Run `goplus lint` on save |
| `goplus.formatOnSave` | `false` | Run `goplus fmt` on save (also works via `editor.formatOnSave`) |

## Commands

| Command | Description |
|---------|-------------|
| **GoPlus: Check Current File** | Run `goplus check` on the active file |
| **GoPlus: Lint Current File** | Run `goplus lint` on the active file |
| **GoPlus: Format Current File** | Format the active file with `goplus fmt` |
| **GoPlus: Navigate to Generated Go** | Jump to the generated `.go` location |
| **GoPlus: Navigate to GoPlus Source** | Jump back to the `.gp` source |

## Source Navigation Setup

For bidirectional navigation to work, generate source maps:

```bash
goplus transpile --emit-source-map your_file.gp --out-dir .goplusgen
```

The extension automatically discovers `.go.map` files in the configured `outDir`.
